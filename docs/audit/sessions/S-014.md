**Objetivo:** detener el release v0.2.0 y preparar v0.2.1 con las correcciones P0/P1 del triaje `triage-external-review-2026-10b.md`.

**Decisiones aplicadas:**
- El tag `v0.2.0` se conserva como tag de desarrollo; no se mueve. No se crea GitHub Release ni depósito Zenodo para v0.2.0.
- El paper se alinea con el circuito ZK entregado: V3 Poseidon + norma, Groth16 directo, 94.438 constraints, 3,9 s, prueba de 128 B (256 B on-chain). La recursión queda como opción diferida, no como diseño adoptado.
- El claim de Cost of Attack se rebaja: se elimina «without degrading» y se declara que el paper precio la admisión, no el coste de adquirir reputación.
- La tabla de auditoría se etiqueta como statics comparativos con `p_fraud` exógeno, no como equilibrio; se añade el bucle `p_fraud -> 0`, `B* -> ∞`.
- Se declara que el publicador de la hoja fraudulenta es el sequencer en v1 y que la atribución al validador no está implementada.
- Se corrige el dominio del tensor (§3), la explicación blocky (rango `K` en modo C, error por modos D/H), el conteo 573 → 3.621, EIP-1108, y las etiquetas mean/median (0,7764/0,3936 son medias; medianas 0,7714/0,4000; reducción mediana 22,86%).
- `f_c` se declara como interfaz/instancia de génesis, no como fórmula fijada en el paper.
- Fuji se acota como test de despliegue/gas, no de incentivos; el block time es una observación de testnet.
