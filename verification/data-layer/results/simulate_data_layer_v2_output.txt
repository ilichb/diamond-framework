NOTAS
==============================================================================

1. A diferencia del modelo v1, la cobertura crece con el número
   de auditores: coverage(n) = 1 - e^{-n}.
2. El equilibrio n_auditores se calcula por condición IR:
   p_fraud · bounty · coverage(n) > c_audit.
3. La detección se satura cuando coverage(n) → 1, no a 0.632.
4. El profit del verificador se reporta para diagnóstico; si es
   persistentemente negativo, el modelo tiene un problema.
